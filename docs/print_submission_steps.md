# 入稿の手順（日光企画・技術書典21）

『五反田TechBook vol.1』を日光企画に入稿するまでの手順。2026-11-16に、日光企画のサイトと入稿フォームを
読み、このリポジトリの`master`（コミット5d95f23）をビルドして確かめた内容でまとめた。

## 前提：ページ数に関わる数字は仮

**2026-11-16の時点で、`master`へのマージがまだ残っている。** この文書の次の数字は、コミット5d95f23の
`master`をビルドした結果で、最後のマージのあとに変わることがある。

- 本文のページ数（136）と、表紙込みのページ数（140）
- 背幅（7.0mm）と、表紙のデータの幅（309.0mm）
- 金額（46,120円）
- 色が残っているページの一覧、はみ出しの件数

最後のマージが済んだら、「やること」の2.でPDFを作り直し、ページ数が変わっていたら下の「ページ数が
変わったとき」の表で背幅・表紙の幅・金額を読み替える。**表紙のデータの仕上げ、見積もり、支払い、
入稿フォームは、最後のマージのあとにやる。**

変わらないもの：締切、セット、サイズ（A5）、冊数（100）、用紙、搬入先。

## 締切

**2026-11-18（水）AM10:00までに、入稿と入金の両方を済ませる。** 表紙も本文も同じ締切。

- この締切までなら通常料金で、予約は要らない。
- 過ぎると割増になる（11/19は5%、11/20は10%、11/21は15%）。11/22は「一日本」で、20%の割増のうえ、
  11/19の10時から始まる予約（先着順）が要る。
- 入金だけでは注文にならない。入金と入稿の両方が日光企画に届いた時点で、注文が確定する。
- 入稿データを送ったあとのキャンセルは、原則できない。

## やること

### 1. 3人で決める

- [ ] 本文を締める時刻（`master`への最後のマージをいつまでに済ませるか。これより後は原稿を変えない）
- [ ] 入稿フォームを送る人、支払いをする人（別の人でもよいが、名義が違うときは日光企画に知らせる）

### 2. 本文のPDFを作る

最後のマージが済んだ`master`で、リポジトリの直下から次を実行する。

```bash
docker run --rm -v $(pwd):/book vvakame/review:5.9 /bin/bash -ci "cd /book/articles && review-pdfmaker --debug config.yml"
```

できた`articles/ReVIEW-Template.pdf`を確かめる。

- [ ] ページ数が偶数（`pdfinfo`の`Pages`）。コミット5d95f23のビルドでは136ページ。
- [ ] ページ数が136から変わっていたら、「ページ数が変わったとき」の表で背幅・表紙の幅・金額を読み替える。
- [ ] フォントがすべて埋め込まれている（`pdffonts`の`emb`の列がすべて`yes`）。コミット5d95f23のビルドでは、すべて`yes`。
- [ ] ログ（`articles/ReVIEW-Template-pdf/__REVIEW_BOOK__.log`）の`Overfull \hbox`（版面からのはみ出し）を見て、
      はみ出しているところを直す。コミット5d95f23のビルドでは29件出ている（下の「はみ出しの警告」）。
- [ ] 意図しない白紙のページがない。
- [ ] 全ページにノンブル（ページ番号）がある。1ページ目（大扉）が「1」で始まる通しの数字になっている。
- [ ] カラーが残っているページを、グレーにした見た目で確かめる（下の「カラーが残っている画像」）。

`config.yml`は`media=print,paper=a5,hiddenfolio=nikko-pc`になっているので、トンボと、日光企画向けの
隠しノンブル（ノドに入るページ番号）は自動で付く。PDFの用紙がB5の大きさ（182×257mm）になるのは、
A5のまわりにトンボを付けているためで、正しい。

#### はみ出しの警告

コミット5d95f23のビルドでは、`Overfull \hbox`が29件出ている。判型をB5からA5に変えた（コミット0eeaa1b）ので、
B5の幅に合わせていた表などが収まらなくなっている。

| 章 | 件数 | いちばん大きいはみ出し |
|---|---|---|
| 第2章（`shimoji.tex`） | 21 | 約8.4pt（約3mm）。同じ幅のものが並んでいる |
| 第3章（`yamane.tex`） | 6 | 約43.6pt（約15mm）。ほかに約37.8pt、約20.8pt |
| 大扉など（`__REVIEW_BOOK__.tex`の124行目） | 1 | 約11.0pt（約4mm） |
| 著者紹介（`contributors.tex`） | 1 | 5pt未満 |

ログの`lines N--M`は、それぞれの`.tex`の行番号。該当のページを`pdftoppm`で画像にして、文字や表が
版面の外（とくに断ち切りの近く）に出ていないか目で見る。直し方は`CLAUDE.md`の「版面からはみ出さない」に
ある（ただし、そこに書いてある列幅の上限はB5のときの値）。

#### カラーが残っている画像

本文はスミ刷りなので、PDFにカラーの画像が残っていても入稿はできて、**グレーで印刷される**（日光企画の
「よくある不備」の4番）。直さなくてよいが、もとの色が薄いと、とても薄いグレーになって見えにくくなる。

コミット5d95f23のビルドでは、次の23ページに色が残っていた（PDFのページ番号）。第1章の1ページ、
第2章の21ページ、著者紹介の1ページで、第3章（96ページから）にはない。

> 17, 25, 27, 30, 33, 36, 37, 39, 43, 46, 49, 52, 55, 58, 63, 67, 71, 75, 79, 84, 89, 93, 134

グレーにした見た目は、次のコマンドで画像にして確かめられる（`gray-008.png`のようなファイルができる）。

```bash
pdftoppm -gray -r 100 -png articles/ReVIEW-Template.pdf gray
```

- [ ] 上のページで、線・文字・塗りが薄くて見えなくなっているところがない。
- [ ] グレーの背景に白い文字、白い背景にグレーの文字で、読みにくいところがない。

### 3. 表紙のデータを作る（PSD）

表紙は、表4（裏表紙）・背・表1（おもて表紙）をつなげた**見開き1枚**で入稿する。下の寸法は本文136ページ
（背幅7.0mm）のときのもの。本文のページ数が変わったら、「ページ数が変わったとき」の表の幅に直す。
`articles/images/cover-a5.ai`（154×216mm）は表1だけの大きさなので、そのままでは入稿できない。

| | 寸法 |
|---|---|
| 仕上がり | 幅303.0mm（148＋7.0＋148）×高さ210mm |
| **入稿データ（塗り足し込み）** | **幅309.0mm×高さ216mm**（四方に3mmずつ足す） |
| 350dpiでのピクセル数 | 4258×2976px |

- [ ] 左から「表4（裏表紙）148mm・背7.0mm・表1（おもて表紙）148mm」の順に並んでいる（左トジのため）。
- [ ] 解像度が350dpi。
- [ ] カラーモードはRGBのままでよい（NPホワイト200kgはRGBのオンデマンド印刷に対応している）。
- [ ] 絵や地の色を、塗り足しの端（データの端）まで伸ばしている。
- [ ] 文字やロゴを、仕上がりの端と背の境目から3mm以上離している（印刷の位置が3mm前後ずれることがある）。
- [ ] レイヤーを1枚に統合して保存している（Photoshopの「レイヤー」→「画像を統合」）。

トンボは付けなくてよい（付いていないデータは、データの中心を基準に位置を決めてもらえる）。

### 4. ファイルをまとめてzipにする

1. 半角英数字の名前でフォルダを作る（例：`gotanda_techbook_vol1`）。
2. 本文と表紙を、半角英数字のファイル名にして入れる。

   ```
   gotanda_techbook_vol1/
   ├── honbun.pdf   本文（136ページ）
   └── cover.psd    表紙（見開き）
   ```

3. 銀行振込で払った場合だけ、振込の控えの画像（スクリーンショットでよい）も同じフォルダに入れる。
4. フォルダをzipにする（Finderでフォルダを右クリック→「圧縮」）。

### 5. 見積もりを取って払う

日光企画は前払い。

**クレジットカードで払う場合**

1. にこぷり.comの「自動見積りシステム」に、「発注の内容」の表のとおりに入れて見積もりを取る。
2. 金額が「ページ数が変わったとき」の表と合っているか確かめて、そのまま決済に進む。
3. 見積もり番号と金額を控える（入稿フォームに書く）。

- 払ったあとでページ数や冊数が増えて不足が出ると、不足分は銀行振込でしか払えない。
  **`master`への最後のマージが済んで、本文のページ数が決まってから払う。**

**銀行振込で払う場合**

- 振込先は[日光企画の「支払い」のページ](https://www.nikko-pc.com/site/home-hd-2/home-pay/)にある。
- 振込の控えの画像を、4.のフォルダに入れてから zip にする。

- [ ] メールアドレスを打ち間違えていない（間違えると、不備の連絡も受付完了のメールも届かない）。

### 7. 送ったあと

- 日光企画の担当者がデータを開くと、開封通知のメールが届く。そのあと受付完了のメールか、不備の連絡が来る。
  11/18の日中はメールを見られるようにしておく。
- 不備の連絡が来たら、Web入稿窓口の「差し替え窓口」から、**最初に送ったデータを全部**送り直す。
- 自分たちの都合での差し替えは、原則できない。入稿フォームを2回送らない（二重に受け付けられて、
  二重に印刷されることがある）。
