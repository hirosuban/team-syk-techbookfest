# 入稿の手順（日光企画・技術書典21）

『五反田TechBook vol.1』を日光企画に入稿するまでの手順。日光企画のサイトと入稿フォームは2026-11-16に読んだ。

## 前提：本文は144ページで確定

**2026-11-17に、本文は144ページで確定した。** この文書のページ数・背幅・表紙の幅・金額は、
本文144ページ（表紙込み148ページ）で計算した値。

- 本文144ページという数字は、2026-11-17に著者が`master`をビルドして確かめたもの。
- はみ出しは、2026-11-17に著者が本文144ページのPDFで確かめた（入稿の不備になるものはない）。
- 「はみ出しの警告」に書いてある件数とページ番号は、2026-11-16にコミットaed037eの`master`（本文136ページの
  とき）をビルドして調べたもの。aed037eのあとに、第1章の追記、3つの章の「章の入り口」、第3章の図が`master`に
  入っているので、本文144ページのPDFでは件数もページ番号も変わっている。
- カラーの画像がグレーでどう見えるかの確認は、やらない（2026-11-17に決めた）。カラーのまま入稿する。

## 締切

**2026-11-18（水）AM10:00までに、入稿と入金の両方を済ませる。** 表紙も本文も同じ締切。

- この締切までなら通常料金で、予約は要らない。
- 過ぎると割増になる（11/19は5%、11/20は10%、11/21は15%）。11/22は「一日本」で、20%の割増のうえ、
  11/19の10時から始まる予約（先着順）が要る。
- 入金だけでは注文にならない。入金と入稿の両方が日光企画に届いた時点で、注文が確定する。
- 入稿データを送ったあとのキャンセルは、原則できない。

## やること

### 1. 3人で決める

- [ ] 入稿フォームを送る人、支払いをする人（別の人でもよいが、名義が違うときは日光企画に知らせる）

### 2. 本文のPDFを作る

`master`で、リポジトリの直下から次を実行する。

```bash
docker run --rm -v $(pwd):/book vvakame/review:5.9 /bin/bash -ci "cd /book/articles && review-pdfmaker --debug config.yml"
```

できた`articles/ReVIEW-Template.pdf`を確かめる。

- [ ] ページ数が144（`pdfinfo`の`Pages`）。
- [ ] ページ数が144でなかったら入稿を止めて、「ページ数ごとの背幅・表紙の幅・金額」の表で背幅・表紙の幅・金額を確かめ直す。
- [ ] フォントがすべて埋め込まれている（`pdffonts`の`emb`の列がすべて`yes`）。コミットaed037eのビルドでは、すべて`yes`。
- [ ] ログ（`articles/ReVIEW-Template-pdf/__REVIEW_BOOK__.log`）の`Overfull \hbox`（版面からのはみ出し）を見る。
      コミットaed037eのビルドでは23件で、どれも入稿の不備にならなかった（下の「はみ出しの警告」）。
      入稿するPDFのログで件数を比べ、増えた分はページを画像にして見る。
- [ ] 意図しない白紙のページがない。
- [ ] 全ページにノンブル（ページ番号）がある。1ページ目（大扉）が「1」で始まる通しの数字になっている。

`config.yml`は`media=print,paper=a5,hiddenfolio=nikko-pc`になっているので、トンボと、日光企画向けの
隠しノンブル（ノドに入るページ番号）は自動で付く。PDFの用紙がB5の大きさ（182×257mm）になるのは、
A5のまわりにトンボを付けているためで、正しい。

#### はみ出しの警告

コミットaed037eのビルドでは、`Overfull \hbox`が23件出ている。2026-11-16にページを画像にして見て、
**23件とも入稿の不備にならない**（版面の外に何も出ていない）ことを確かめた。

| 場所 | 件数 | 入稿の不備になるか | 中身 |
|---|---|---|---|
| 第2章（`shimoji.tex`）の図 | 21 | ならない | 図とキャプションを囲む`minipage`に字下げが付いて、囲みの幅が約3mm（8.4pt）超えているだけ。図は本文の幅の68%（1つだけ75%）で、版面の外には出ていない |
| 大扉（`__REVIEW_BOOK__.tex`の124行目） | 1 | ならない | 約4mm（11.0pt）の警告だが、題名も著者名も版面の中央に収まっている |
| 著者紹介（`contributors.tex`） | 1 | ならない | 3.8pt。版面の外には出ていない |
| 第3章（`yamane.tex`）の表 | 0 | （直した） | コミット5d95f23のビルドでは、表6つが右に約7〜15mmはみ出していた。PR #15（コミット99327bb）で列幅をA5に合わせ、0件になった |

第3章の表6つ（PDFの104・110・113・115・121・129ページ）は、コミットaed037eのビルドを画像にして、
版面に収まっているのを確かめた。

第2章の21件は、直さなくても入稿できる。直す場合は、`//raw[|latex|\\begin{minipage}{\\textwidth}]`の
`\\begin`の前に`\\noindent`を足すと、字下げが消えて図が版面の中央に来る。

入稿するPDF（本文144ページ）のログで、`Overfull \hbox`の件数をこの表と比べる。増えていたら、
増えた分のページを`pdftoppm`で画像にして、文字や表が版面の外に出ていないか目で見る
（ログの`lines N--M`は、それぞれの`.tex`の行番号）。A5の版面の左右の余白は約16mmなので、
15mmはみ出すと、断ち切りの約1mm手前（偶数ページではノド）まで来る。

#### カラーが残っている画像

本文のPDFには、カラーの画像が残っている（第1章・第2章・著者紹介。コミットaed037eのビルドでは23ページ）。
本文はスミ刷りなので、カラーのまま入稿できて、**グレーで印刷される**（日光企画の「よくある不備」の4番）。
もとの色が薄いと、薄いグレーになって見えにくくなることがある。

グレーにした見た目を入稿の前に確かめることは、やらない（2026-11-17に決めた）。カラーのまま入稿する。

### 3. 表紙のデータを背幅に合わせて直す（PSD）

表紙のデータ（PSD）は、デザイナーが作ったものがすでにある。**新しく作る必要はなく、本文144ページで
決まった背幅（7.4mm）に合わせて、そのPSDの幅を直すだけ。** 直したあと、下の寸法とチェックで確かめる。

表紙は、表4（裏表紙）・背・表1（おもて表紙）をつなげた**見開き1枚**で入稿する。

| | 寸法 |
|---|---|
| 仕上がり | 幅303.4mm（148＋7.4＋148）×高さ210mm |
| **入稿データ（塗り足し込み）** | **幅309.4mm×高さ216mm**（四方に3mmずつ足す） |
| 350dpiでのピクセル数 | 4263×2976px |

- [ ] 左から「表4（裏表紙）148mm・背7.4mm・表1（おもて表紙）148mm」の順に並んでいる（左トジのため）。
- [ ] 解像度が350dpi。
- [ ] カラーモードはRGBのままでよい（NPホワイト200kgはRGBのオンデマンド印刷に対応している）。
- [ ] 絵や地の色を、塗り足しの端（データの端）まで伸ばしている。
- [ ] 文字やロゴを、仕上がりの端と背の境目から3mm以上離している（印刷の位置が3mm前後ずれることがある）。
- [ ] レイヤーを1枚に統合して保存している（Photoshopの「レイヤー」→「画像を統合」）。

トンボは付けなくてよい（付いていないデータは、データの中心を基準に位置を決めてもらえる）。

### 4. ファイルをまとめてzipにする

1. 半角英数字の名前でフォルダを作る（例：`gotanda_techbook_vol1`）。
2. 本文と表紙を、半角英数字のファイル名にして入れる。

   ```
   gotanda_techbook_vol1/
   ├── honbun.pdf   本文（144ページ）
   └── cover.psd    表紙（見開き）
   ```

3. 銀行振込で払った場合だけ、振込の控えの画像（スクリーンショットでよい）も同じフォルダに入れる。
4. フォルダをzipにする（Finderでフォルダを右クリック→「圧縮」）。

### 5. 見積もりを取って払う

日光企画は前払い。

**クレジットカードで払う場合**

1. にこぷり.comの「自動見積りシステム」に、「発注の内容」の表のとおりに入れて見積もりを取る。
2. 金額が48,170円になっているか確かめて、そのまま決済に進む。
3. 見積もり番号と金額を控える（入稿フォームに書く）。

- 払ったあとでページ数や冊数が増えて不足が出ると、不足分は銀行振込でしか払えない。
  本文は144ページで確定しているので、見積もりは表紙込み148ページで取る。

**銀行振込で払う場合**

- 振込先は[日光企画の「支払い」のページ](https://www.nikko-pc.com/site/home-hd-2/home-pay/)にある。
- 振込の控えの画像を、4.のフォルダに入れてから zip にする。
